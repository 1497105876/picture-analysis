## 1. 产品介绍

**picture-analysis 是什么：** 一个本机运行的**规范化图片索引数据库 + Web 管理界面**。它把你指定的图片目录扫描入库，用 AI 识图（分类/描述/标签/元素/OCR）补全语义，再提供关键词+语义混合检索、人工审核、规则分类、去重清理等一整套管理能力。

**核心理念：找图是能力，索引是本体。**

- **对外的真正接口是那个 SQLite 数据库文件**（`data/library.db`）。本机 Agent（QClaw / openclaw / workbuddy 等）只读直连即可查询，不装任何东西、不起任何服务、**不做 MCP Server**。
- Web 界面是管索引、做人工审核的工具：登记目录、触发扫描、看 AI 结果、纠错打回、搜索、清理、隐藏。
- **人工永远优先**：你改过的分类/描述/标签，AI 和规则都不能覆盖。
- **一切从简的手动控制**：目录必须你手动登记（不自动扫）、OCR 按需触发、识图默认限速 20 次/分钟、每日 token 上限触顶自动停。

**给谁用：** 本机 Agent 生态的图片记忆基建；以及任何想把散落图片变成"可搜、可审、可被程序查询"的索引的个人用户。

**运行形态：** 本地 Web（`python server.py` → 浏览器打开 `http://127.0.0.1:8321`），只监听 127.0.0.1，外部不可达。交付物是 Release zip，**无部署**、无桌面壳。

## 2. 安装与启动

### 2.1 源码运行（开发/自建）

```powershell
# 需要 Python 3.12
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"

copy .env.example .env     # 填 OpenAI 兼容 API Key（也可启动后在设置页填）

start.bat                  # Windows；Linux/macOS 用 ./start.sh
# 或手动：python server.py   →  http://127.0.0.1:8321
```

### 2.2 Release 包运行（普通用户）

解压 `release/picture-analysis-0.1.0.zip`（或 CI 的 package artifact），双击 `start.bat`。前端已打进包内，**不需要 Node/npm**。

### 2.3 首次打开的 5 步（真实用户流程）

1. **设置页 → 服务档案**：新建档案，填 `base_url` + `API Key`（**明文可见、可复制**），点「探测」看延迟与能力；把「识图/嵌入/对话/查询增强」四个用途绑定到档案（可选"跟随识图"）。云端 OpenAI 兼容接口和本地 Ollama / LM Studio 都支持。
2. **图库 → 登记目录**：点「登记目录」→ 选文件夹 → 系统先给**预估**（张数/字节/预估 token/预估耗时、是否超预算）→ 确认后落库并排队扫描。**未登记的目录一概不会被扫。**
3. **等待扫描入索引**：缩略图、宽高/大小/mtime/EXIF 拍摄时间/主色调、MD5 全部生成；消失的文件标记「文件丢失」但记录不删。
4. **队列页看 AI 分析**：识图任务自动排队执行（默认限速 20 次/分钟、≥3 秒一次），产出分类/描述/AI 标签/元素清单；识图判定"图中含文字"才追加 OCR（结果独立存表）。可停止、可重试、失败自动重试、缺 Key 时任务**暂停并提示**。
5. **检索页找图**：关键词 + 语义 RRF 混合默认生效（搜"夕阳下的海滩"能命中写"傍晚海岸"的图），支持分类/标签/评分/收藏/目录/时间筛选、跳页 + cursor 深分页、搜索历史与同义词。

## 3. 功能全景（F1–F15）

### F1 图片入库 ✅（部分接口项界面未露出）

- **手动登记（两阶段）** ✅：图库页「登记目录」→ 预估 → 确认入库；`POST /api/directories` 不带 confirm 返回预估，带 `?confirm=1` 落库。
- **递归开关 / 扩展名白名单 / 排除 glob** ✅：向导内递归开关；全局白名单与排除在 **设置 → G4 目录策略**。
- **增量扫描** ✅：新文件入库、mtime 变更重提取、消失文件标 `missing`（卡片标红），记录不删。
- **离线盘（插回复活）** ⚙️：目录有 `offline` 标志，`PATCH /api/directories/{id}` 可切，重新扫描即复活——**界面暂无离线标识与操作**。
- **目录级策略** ⚙️：每目录可配 `enabled / offline / privacy / frozen / watcher / ocr_policy / recursive`（API 全支持）——**目录卡片目前只有"启用/停用"**，其余开关界面暂未露出。
- **导入向导预估** ✅（张数/耗时/成本/是否超预算，先入库后识别两阶段）。
- **元数据** ✅：宽高、大小、mtime、EXIF 拍摄时间（可按 `taken` 排序/时间筛选）、主色调。
- **缩略图** ✅ 统一生成（`/api/thumbs/{id}`）。
- **MD5 内容哈希** ✅：同内容共存入库；移动/改名按 hash 认回原身份（标注不丢）。

### F2 AI 识图管线 ✅

- OpenAI 兼容 VLM 逐张产出：**分类 + 描述 + AI 标签（3~5，与人工标签分开存、合并搜）+ 元素清单 + 图中文字**。
- **OCR 按需触发** ✅：识图时判定含文字才追加 OCR 请求，结果落独立表；判定阈值、`ocr_mode`、目录强制开关在 **设置 → G5 OCR**。
- 字段可独立开关省 token（**G2 识别行为**：description/tags/elements/has_text）。
- 后台队列 ✅（**队列页**）：并发可配、失败重试上限、实时进度、可停止/重试/取消、优先级（普通=10、打回重识别=100、扫描/嵌入=0）。
- **限速** ✅：全局限速默认 **20 次/分钟（≥3 秒一次）**、过夜限速可配（**G3 并发与限速**）；暂停状态在队列页可见。
- **成本记账** ✅：每次请求记 tokens，仪表盘看累计；批量前预估；**每日 token 上限触顶自动暂停、次日恢复**（G3 `daily_token_limit`）。
- **prompt 模板** ✅ 可编辑覆盖（G2 `vision_prompt_override`）。
- **软失败** ✅：识图挂了，入库/管理/关键词搜索照常；缺 Key 启动零外发、队列暂停有提示。

### F3 搜索（核心）✅

- FTS5 全文（文件名/描述/标签/备注，jieba 中文分词）+ 向量余弦，**混合 RRF 默认模式**（G6 `search_mode/rrf_k/similarity_threshold`）。
- 筛选可叠加：分类/标签/评分/收藏/目录/时间/`q` 全文；**跳页 + cursor 游标**深分页（10 万级不卡）。
- **LLM 查询增强**可开关（G6 `query_enhance`，失败自动回退原词）。
- **同义词组与术语加权**（猫=喵星人，G12）、**搜索历史**开关与清除（搜索页直接可清）。

### F4 图库管理 ✅（自定义字段界面未露出）

- 标签多值、评分 0–5、收藏、备注；缩略图网格 + 大图抽屉（**上一张/下一张**、键盘 ←→）。
- **批量**打标/评分/分类/收藏/隐藏/删除（`POST /api/images/batch`；批量删除仅支持只删索引，源文件删除必须逐张确认词）。
- **智能相册** ✅：当前筛选+搜索+排序存为命名视图（**相册页**），侧栏一键回放。
- **自定义字段**（text/数值/日期/下拉）⚙️：`/api/custom-fields` 已就绪——**界面暂无管理入口**。

### F5 系统设置 ✅

- **schema 驱动**：后端定义分组/控件/默认值，设置页自动渲染，新增配置零 UI 代码。
- 档案卡片（增删改 + 探测按钮 + 四用途下拉绑定，可"跟随"）；**密钥明文可见、可编辑、可复制**（存 `.env`，不进日志/数据库/导出物）。
- 连接探测出延迟与能力；**审计与单项回滚**（`/api/settings/audit`、`rollback`）、**Profile 配置方案**快照/切换/导入导出、**一键备份**。

### F6 人工纠错与打回 ✅（计数/筛选未露出）

- 详情抽屉直接修改分类/描述/标签/备注，**保存即生效**，AI 不再覆盖；FTS 即时更新。
- **打回重识别** ✅：可填纠正说明 → 下次识别 prompt 携带人类反馈重新生成（优先级 100）。
- 打回计数与"已人工纠错"筛选 ⚙️（AC 有要求，界面暂未露出标记与筛选）。

### F7 参考资料库 ✅

- 实体页：名称+别名+类别+特征描述+参考图 1~N（上传、删除、停用）；手动关联/解除关联图片。
- 识别时**三路注入**：手动关联全量 + 名称/别名硬匹配 + 实体向量召回 top-3，每实体参考图最多 2 张；参考图独立目录存储并压缩省 token；停用实体不注入。

### F8 文件与图库操作 ✅（"打开位置"/复制未露出）

- **删除双模式** ✅：默认只删索引（源文件不动）；删源文件必须**逐张输入文件名确认** → 进**回收站**（恢复/清空需打"清空回收站"确认词），绝不物理直删。**只删索引的图后续增量扫描不会再收录**（扫描提示会显示「已排除「仅移除索引」N 张」；注销该目录后重新登记 = 全量重来，可让图片重新入库）。
- 重命名 ✅（库内同步改绑，hash 身份与标注不变）、移动到其他已登记目录 ✅。
- 复制到其他目录 🚧（仅移动）、"打开所在位置" 🚧（界面与接口均未提供）。

### F9 导入与浏览增强 🚧（最大的界面缺口）

- 上传按钮导入 ✅；**拖文件夹/拖文件导入** ❌、**Ctrl+V 粘贴导入** ❌。
- 大图 **←→ 连续切换** ✅（抽屉内上一张/下一张 + 方向键）；**旋转** ❌。
- **幻灯片全屏轮播** ❌。
- 目录筛选 ✅（下拉选择目录）；**真实目录层级树** 🚧（下拉非层级树）。

### F10 扩展功能 🚧

- **仪表盘** ✅：分类分布、月份趋势、重复情况、识别状态、存储占用；数字与手算一致。
- **重复清理向导** 🚧：MD5 精确组 + dHash 感知聚类可看（`?perceptual=1`）；**"每组引导保留一张"的引导按钮没有**——需要回图库逐张操作（只移索引不动源文件的规则不变）。
- **截图自动导入** 🚧：已登记目录 30 秒轮询监听 ✅（开关在 **G4 `watcher_enabled`**，每目录 `watcher` 开关走 API）；**剪贴板轮询 ❌**。
- **以图搜图** 🚧：**库内相似** ✅（大图抽屉「相似」按钮，embedding 检索）；**上传一张图找相似 ❌**。

### F11 对话式问答 ✅

- **对话页**：自然语言问图库 → LLM 解析成结构化条件并**回显** → 混合检索 → 回答 + 图片卡；解析失败/服务挂**软降级**为引导语 + 关键词结果，不弹错。
- **提案队列 ✅**：对话产生的实体/标签建议只进提案，**一键批准**才入库，批准前库零变化（**提案页** 批准/拒绝）。
- 口径：一次性 JSON 应答，**不做 SSE**（见 design.md 第 9 节）。

### F12 SQLite 直读规范 ✅

- 数据库文件即对外接口：`sqlite3 "file:data/library.db?mode=ro"` 即查，不装东西、不起服务。
- **只读铁律**：直读只查不写，一切写入经人工 UI；隐藏区默认过滤且**无绕过参数**；`COALESCE` 人工字段优先于 AI 字段；字段语义与 `docs/design.md`「SQLite 直读契约」逐字一致，随库提供表结构与查询示例（`docs/examples/`）。

### F13 分类规则引擎 ✅

- **规则页**：IF（目录前缀/后缀/文件名/OCR 文本/分类）→ THEN（设分类/追加标签/进智能相册）；可排序、逐条开关、**首条命中即停**。
- **试跑先行** ✅（只预览命中不落库）、**历史图一键补算** ✅（`POST /api/rules/recompute`，幂等）。
- 两阶段求值（入库即判 + OCR 完成后复算）✅；只写 AI 分类位，**人工分类绝不覆盖**。

### F14 自定义分类与手动分类 🚧（管理界面缺失）

- 手动归类 ✅（详情抽屉单选分类 + 批量改分类）；分类/标签两维都进筛选与搜索。
- 分类字典接口 ✅（`GET/POST/PATCH/DELETE /api/categories`：新增、重命名、停用）——**界面暂无管理入口**；**合并分类级联** ❌（接口未实现）。

### F15 隐藏区 ✅

- 单张/批量隐藏 → 前端、搜索、相册、**Agent 直读**全部不可见，无参数可绕过；文件仍在原处、识别备份照常。
- **隐藏区页**集中查看与批量恢复，入口有可见性说明条；与"隐私模式"（临时不外发）区分。

## 5. 对外接口：怎么给 Agent 用

```bash
# 只读直连，不起任何服务
sqlite3 "file:data/library.db?mode=ro"

# 典型查询（隐藏区默认排除、人工字段优先）
SELECT id, path,
       COALESCE(NULLIF(description_manual,''), description_ai) AS description,
       COALESCE(NULLIF(category_manual,''), category_ai) AS category
FROM images
WHERE missing = 0
  AND id NOT IN (SELECT image_id FROM hidden)
ORDER BY mtime DESC LIMIT 20;
```

- 完整表结构、字段语义、查询示例：`docs/design.md`「SQLite 直读契约」+ `docs/examples/`。
- 铁律：直读**只查不写**；管理操作（扫描/识别/删除）一律走 Web 界面。

## 7. 你的原始需求与口径对照（11 条原话 + 6 条口径）

| 你说的原话 | 落点 | 状态 |

| 使用 ai 对图片进行分析 | F2 识图管线 | ✅ |
