## 我演的是谁

**小李**，照片散在硬盘各处、微信图和截图混在一起，听人说有个本地工具能管图、还能 AI 自动识别，于是打开看看。
**他不知道 API key 是什么，也没配 AI 服务**——这就是大多数人的第一次。

## 第 1 幕：打开，我的照片呢？

**目的**：看看这东西能不能看到我的照片。

**我做了什么**：浏览器打开 `http://127.0.0.1:8321`。

**我看到什么**（`_shots/beta/01-第一次打开.png`）：

```
picture-analysis
图库
已索引 0 张
[登记目录] [上传图片]

已登记目录  1
只扫登记过的路径；未登记目录一概不碰
C:\Users\highness\Pictures\3D
```

**我的感受**：空的。但下面那句「只扫登记过的路径；未登记目录一概不碰」让我松了口气——它不会偷偷扫我整个硬盘。这个态度我喜欢。

**发现的第一个别扭**：侧栏有两个「新」标记（分类 / 运维），我点开之前不知道"新"是什么意思，也不确定这两个是不是我这版本才有的。

---

## 第 2 幕：登记我的照片目录

**目的**：把照片目录加进去。

**我做了什么**：点「登记目录」→ 弹窗出来 → 我想点「浏览…」选文件夹。

**实际**（`_shots/beta/02-登记弹窗.png`）：

```
两步走：先估数（不写库不调用 AI），确认后再落库扫描。
未登记的路径永远不会被碰。
目录绝对路径  [                    ]
必须已存在于本机，且在有权限访问的位置。
```

**我的感受**：
- **没有「浏览…」按钮**。我得切到资源管理器、找到目录、复制路径、再切回来粘贴。第一次用就卡在这。
- 不过那句「不写库不调用 AI」写得很实在，让我愿意往下走。

**我做了什么**：粘上 `Z:\我的照片` → 点「第一步：估算」。

**实际**（`_shots/beta/03-估算结果.png`）：

```
在日预算内
发现文件    4 个 · 40.5 KB
预计耗时    约 0.7 分钟
预计 token  3,600 （未设上限）
phase-1 扫描入库（不调用 AI）
phase-2 识别（分批排队，可随时暂停）
```

**我的感受**：**这里是全程体验最好的地方**。先告诉我多少张、要多久、要花多少 token，还分了两个阶段。我不怕了，点「第二步：确认登记」。

**实际**：4 张照片立刻出现，页面显示「已索引 4 张 · 本页 40.5 KB」✓

---

## 第 3 幕：照片进来了，然后呢？

**目的**：等它自动识别，给我分类和描述。

**我做了什么**：等了几秒，看着那 4 张卡片。

**实际**：卡片右下角标着「排队中」，没有分类、没有描述，写着「（尚无描述）」「未分类」，尺寸那行是 `256×114 · 0`。

**我的感受**：
- 等了一会儿没动静。**页面上没有任何一句话告诉我"为什么不识别"**——我不知道是没配 AI、还是卡住了、还是要等更久。
- 那行 `256×114 · 0` 我看不懂：照片 6 KB 显示成「0」，等于没信息。

**这就是一个新手最典型的流失点**：照片进来了，期待的"AI 自动整理"没发生，而界面对此**一声不吭**。
（真相是：我没配 AI 服务档案，队列其实已经 `paused：识图服务未配置或缺少 API Key`。这个信息只存在于**任务页**，而一个新手不会想到去那儿看。）

---

## 第 4 幕：想去后台看看它在干嘛

**目的**：看看后台是不是卡住了。

**我做了什么**：点左侧「运维」。

**实际**：**整个页面全白了**。侧栏没了，顶栏没了，什么都没了。我试着点点点——**点什么都没反应**。
刷新页面——回到了图库。

**我的感受**：懵。「我是不是把它弄坏了？」第一反应是我自己的问题。然后我发现只有刷新能救回来，而且刷新后我刚才的位置也没了。

> 这一幕在本轮测试里**反复出现**，不是偶发。只要通知数据一到，Vue 外壳就崩，之后所有点击全部失效——**页面看着还在，其实已经死了**。
> 这就是你感觉"还是有一些问题"的真正来源。

## 第 5 幕：点开一张照片看看

> 为了让后面的旅程能走完，我在这里临时修了那一行导致崩溃的 bug，重跑了一遍。**下面几幕是"修好之后"的体验**，代码我测完已经回滚了。

**目的**：看看它认出了什么。

**我做了什么**：点第一张照片 → 抽屉从右边滑出来（`_shots/beta/06-抽屉详情.png`）。

**我看到什么**：大图、状态标签、「纠错 0 次」、路径、尺寸时间 MD5，然后是「人工修正」区（分类 / 描述 / 标签 / 评分 / 收藏 / 备注），再往下是「AI 识别结果」「相似图片」「文件操作」。

**我的感受**：信息量很足，比我想象的完整。

**我做了什么**：点开分类下拉，想选「风景」。

**实际**：

```
分类
  （不指定，回落到 AI 分类）
  （空）
```

**我的感受**：「应该有风景、人物这些吧？」结果只有一个「不指定」和一个空选项。
（真相：分类字典没被正确读进来，下拉里那个空选项其实是数据结构的键名"items"——**这是坏得很具体的一个 bug**。）

**我做了什么**：给它打 4 星，点「保存修正」。

**实际**：保存成功，有提示。但我不确定它存没存——提示一闪而过，抽屉也没什么明显变化。

## 第 6 幕：这张不想要了，删掉它

**目的**：删掉一张废图。

**我做了什么**：把抽屉拉到底，找到「文件操作」区。

**实际**（`_shots/beta/08-抽屉底部.png`）：

```
AI 识别结果
  AI 分类 —  · 分析记录 0 条
  还没有 AI 描述（未识别或识别失败）。
相似图片
  按向量相似度召回，隐藏区不参与
  没有相似图
  嵌入向量不可用，以图搜图暂时无法工作
文件操作
  改名/移动会真实改动磁盘上的文件，删除源文件先进回收站
  [改名] [移动到目录…]
  只删索引（源文件保留） ▾
  [删除]
```

**我的感受**：
- 「嵌入向量不可用，以图搜图暂时无法工作」——**这句写得非常好**，直接告诉我这个功能是坏的、为什么坏。我希望其他地方也能这么说话。
- 点「删除」→ 弹窗出现。我选「删除源文件」后，它让我**输入文件名**才能删。
- 第一反应是「为什么要我输文件名？」但看清楚是防误删之后能接受——**这个设计是对的，只是弹窗没解释为什么**，我得自己猜。

---

## 第 7 幕：建个相册归归类

**目的**：把照片按分类放进相册。

**我做了什么**：点「相册」→ 填名字「我的收藏」→ 想在可视化模式下选分类。

**实际**（`_shots/beta/10-相册页.png`）：分类下拉只有 1 个可用选项（和第 5 幕同一个 bug），评分下拉 6 项、目录下拉 3 项都是正常的。

**我的感受**：分类选不了，我只能切到 JSON 模式手写 `{"category":"风景"}` ——**对一个新手来说这是劝退级别的操作**。

---

## 第 8 幕：换个外观

**目的**：暗色看着舒服点。

**我做了什么**：点「设置」→ 点「暗色」。

**实际**：`data-theme` 立刻变成 `dark`，整站跟着变。再点第 4 个色块，强调色变成紫罗兰。

**我的感受**：**这一段很爽**。即时生效、不用保存、刷新后还在。6 个预设色 + 一个自定义取色器，够用。

---

## 第 9 幕：刷新一下，刚才的呢？

**目的**：继续刚才的操作。

**我做了什么**：刷新页面。

**实际**：刚才打开的那张照片的详情抽屉没了，我得重新点进去。筛选条件也回到默认。

**我的感受**：小别扭。但我能忍——**如果抽屉能用 URL 记住（比如 `/gallery?image=3`），刷新就不丢了**，而且还能把某张图发给以后的自己。

## 我最想让你修的三件事（按"新手流失风险"排序）

1. **崩溃**（第 4 幕）——一行代码的事，但不修，任何人用第二次就会撞上。
2. **分类读不进来**（第 5、7 幕）——同样是两行。不修，"分类/相册/字段"这一整块功能对新手等于不存在。
3. **没配 AI 时一声不吭**（第 3 幕）——这是我最想加的东西，也是最容易被当成"功能没做"的地方：
   > 建议在图库页顶部加一条横幅：**「4 张已入库，但还没配置 AI 服务，识别队列已暂停」** + 一个按钮「去配置」。
   > 现在这个信息埋在任务页里，新手根本不会去看。

排在这三条之后的，是时间差 8 小时、内容被压窄、没有文件夹选择器这些。

## 和上一份文档的区别

上一份 `04-模拟用户使用与功能对比.md` 我写成了**功能验收清单**（哪些能用、哪些没有、哪些坏了），看着像 QA 报告，不是 beta 测试。
