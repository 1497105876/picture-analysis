# 第二轮前端重写：实现记录与验收清单

> 完成时间：2026-09-30　上游文档：[`01-前端功能分析.md`](./01-前端功能分析.md)、[`02-重构方案.md`](./02-重构方案.md)
> 后端契约未做任何改动；前端从 12 个页面 / 1 份样式表，重建为 14 个页面 / 3 层结构。

---

## 1. 落地结构

```
frontend/src/
├── main.js            createApp + 兜底 unhandledrejection
├── router.js          14 条路由全量懒加载 + meta.title + 滚动复位
├── App.vue            侧栏 / 顶栏 / 断连横幅 / 唯一轮询点 / ToastHost
│
├── app/               全局单例（页面不再各自请求 /api/settings）
│   ├── api.js         85 个端点，错误统一为「后端人话」+ code + status
│   ├── settings.js    schema + values + profiles；脏值保存；外观派生与落盘
│   ├── notices.js     通知水位线未读计数 + 后端健康探测
│   ├── catalog.js     分类字典与自定义字段缓存
│   ├── toast.js       唯一反馈通道
│   ├── format.js      格式化 + 状态/规则/字段等业务字典
│   └── useList.js     首屏 / 翻页 / 出错三态加载器
│
├── styles/
│   ├── tokens.css     中性色（亮/暗）+ 6 套强调色 + 派生软色 + 8px 尺度令牌
│   ├── base.css       重置 / CJK 字体栈 / 原子类 / 动画
│   └── components.css 按钮 / 表单 / 面板 / 卡片 / 表格 / 抽屉 / 弹窗 / toast …
│
├── components/        18 个（见 §2）
└── pages/             14 个（见 §3）
```

**规模**：前端源码约 9000 行（原 2400 行）；`npm run build` 产物 `index.js` 134.7 KB（gzip 52.5 KB）、`index.css` 28.8 KB（gzip 6.5 KB），页面级 chunk 各自 3–20 KB 按需加载。

## 2. 组件层（18 个）

| 组件 | 作用 |
|---|---|
| `Icon` | 内联 SVG 图标集（40+ 个，24×24 描边，`currentColor`），零依赖 |
| `Panel` | 区块容器：标题 / 副标题 / 计数 / 操作栏 / 可折叠 / danger 变体 |
| `StatCard` | 大数字统计卡，可点击（仪表盘状态卡跳转带筛选的图库） |
| `ImageCard` | 单图卡片：缩略图（404 自动降级占位）+ 分类 + 星级 + 状态点 + 收藏星 |
| `ImageGrid` | **核心**：网格/列表双视图、多选与全选、cursor 无限滚动（IntersectionObserver）、骨架、空态 |
| `ImageDrawer` | **核心**：预览 / 元信息 / 人工修正（含自定义字段）/ AI 结果 / 识别历史时间线 / 相似图 / 改名 / 移动 / 隐藏 / 打回 / 删除，← → 翻图、Esc 关闭 |
| `ConfirmDialog` | 替代 `window.confirm` 与 `window.prompt`，支持「确认词」与「输入值」两种模式 |
| `Modal` | 基础浮层：遮罩关闭、Esc、body 滚动锁定 |
| `EmptyState` | 统一空态（内联 SVG + 标题 + 说明 + 主行动） |
| `Skeleton` | 骨架屏：cards / rows / lines / stats 四种形态 |
| `ToastHost` | toast 队列（info/ok/warn/error，可手动关） |
| `SettingItem` | schema 驱动渲染单配置项：int/float/bool/select(+free)/text/tags/csv |
| `TagInput` | 标签输入（回车/逗号分隔，退格删末尾，可带建议） |
| `StarRating` | 0–5 星级，再点一次清零 |
| 其余 | `Skeleton`、`EmptyState` 已列；`Panel`/`StatCard`/`Modal` 见上 |

## 3. 页面层（14 条路由）

| 路由 | 状态 | 本轮变化要点 |
|---|---|---|
| `/gallery` | 重写 | 分类下拉改读真字典；目录区升级为策略卡（递归/启用/离线盘/隐私/冻结/OCR 档/自动跟踪）；批量新增「加收藏」「CSV 导出」；整块拖拽上传；滚动加载；支持 `?analysis_state=` 进入 |
| `/search` | 重写 | 补齐 cursor 翻页；结果头拆出「总/关键词/向量」三档耗时条；降级显式说明 |
| `/dashboard` | 重写 | 新增「目录占用」区块；重复检测加「可能较慢」确认与汉明阈值；统计卡可点跳转 |
| `/entities` | 重写 | 详情双栏；关联图片渲染缩略图与文件名；可启停 |
| `/rules` | 重写 | 结构化 IF/THEN 构建器；试跑结果改为表格弹窗；优先级上下移；补算二次确认 |
| `/albums` | 重写 | 卡片墙 + 封面（前 8 个各取 1 张）；可视化 query 编辑器与 JSON 双模式 |
| `/chat` | 重写 | 复用统一抽屉（原来是自造残缺抽屉）；展示解析结果 chips |
| `/hidden` | 重写 | 保留说明条语义；视图切换；批量恢复/删索引 |
| `/trash` | 重写 | 恢复/清空，确认词走 ConfirmDialog |
| `/jobs` | 重写 | 轮询开关（默认 3 秒，可暂停）；事件回放按 level 着色为时间线；状态卡可点筛选 |
| `/proposals` | 重写 | payload 结构化渲染（不再裸 JSON） |
| `/settings` | 重写 | 外观区；分组搜索；脏值保存（不再 92 项全量 PUT）；档案密钥显隐；分用途连接探测；侧栏模块勾选排序 |
| `/ops` | **新增** | 健康与版本、通知中心、日志查看器（100–2000 行可调）、存储、SQLite 直读契约 + 示例 SQL、清理任务、清空索引 |
| `/categories` | **新增** | 分类字典 CRUD（内置锁）、自定义字段、同义词组、术语权重 |

## 4. 消灭的差距（分析文档 §3.4 的 14 项）

| # | 能力 | 落点 |
|---|---|---|
| 1 | 通知中心 `/api/notices` | 顶栏铃铛（水位线未读角标 + 下拉）+ 运维页全量列表 |
| 2 | 日志查看器 `/api/logs` | 运维页，等宽字体 + 行数选择 + 当前级别 |
| 3 | 健康状态 `/api/health` | 顶栏处理器图标 + 断连横幅 + 运维页统计卡 |
| 4 | 分类字典 `/api/categories` | 分类页 CRUD；图库筛选与抽屉分类下拉改读真字典 |
| 5 | 自定义字段 `/api/custom-fields` | 分类页管理；抽屉「人工修正」区渲染并回填 |
| 6 | 改名 `/rename` | 抽屉「文件操作」区，带同名/非法字符说明 |
| 7 | 移动 `/move` | 抽屉内选择目标登记目录 |
| 8 | 目录高级策略 | 目录卡：离线盘 / 隐私 / 冻结 / OCR 档 / 自动跟踪 |
| 9 | 分用途连接探测 `usage` | 设置页先选「识图/嵌入/对话/增强」再探测 |
| 10 | 批量 `patch` | 图库批量「加收藏」（可扩展评分/标签） |
| 11 | CSV 导出 | 导出弹窗选 json / csv |
| 12 | 存储分布 `dashboard.storage` | 仪表盘「目录占用」区块 |
| 13 | SQLite 直读契约 | 运维页：只读打开方式 + 视图清单 + 示例 SQL + 复制按钮 |
| 14 | 任务事件分级 `level` | 任务页事件回放按 level 着色 |

同时修掉的隐性 Bug：列表原本读 `image.category` / `image.description`，但后端 `SELECT *` 只有 `category_ai/category_manual`——**旧卡片永远显示「未分类」**，现在统一走「人工位优先」合并。

## 5. 验证结果

**构建**（`npm run build`）：零 error、零 warning，2.6s 完成，14 个页面各自成 chunk。

**接口冒烟**（隔离 `PA_DATA_DIR` 的临时目录 + FastAPI TestClient，未启动常驻服务、未触碰真实库）：

```
200 /api/health   /api/settings   /api/images   /api/hidden   /api/notices
200 /api/logs     /api/categories /api/custom-fields /api/albums /api/rules
200 /api/directories /api/stats/dashboard /api/stats/system /api/stats/cleanup
200 /api/jobs     /api/trash      /api/entities /api/proposals /api/search?q=海
200 /api/synonyms /api/term-weights /api/settings/profiles /api/settings/audit

隐藏区绕过 ?hidden=1        → 400 HIDDEN_NOT_BYPASSABLE
非法排序   ?sort=nope       → 422 不支持的排序字段：nope
SPA 回退   / 与 /gallery    → 200 text/html
静态资源   /assets/*.css    → 200
OpenAPI    /api/docs        → 200
登记不存在目录              → 404 目录不存在或不可访问：Z:\definitely\not\here
失败项：无
```

**后端门禁**：`ruff check` 通过、`ruff format` 69 文件已格式化、`mypy strict` 51 文件无问题、架构门禁通过（修复见 §6）。`pytest` **94 passed**（本机 `--basetemp` 指定到项目内才跑得通，默认 Temp 目录有符号链接权限问题，与代码无关）。

**尚未做的视觉走查**：受「不自动启动常驻进程」约束，本次没有启 `python server.py` 做真实数据渲染截图。构建与接口两层已验证，界面观感需要你启动服务后过一眼。

## 7. 验收清单（启动服务后逐条过）

**主题**
- [ ] 亮 / 暗 / 跟随系统切换即时生效，刷新保持
- [ ] 6 套强调色（顶栏调色板图标）切换后，按钮、链接、选中态、tag 一齐变化
- [ ] 暗色下抽查：次要文本、tag、表头无低对比

**功能**
- [ ] 顶栏铃铛显示未读数，下拉可见通知，可清空
- [ ] 运维页日志查看器能切行数、看到真实日志
- [ ] 分类页能建/改色/停用分类；自定义字段能建能删；抽屉里能填自定义字段值
- [ ] 抽屉内能改名、能移动到其他登记目录
- [ ] 目录卡能改离线盘/隐私/冻结/OCR 档/自动跟踪
- [ ] 设置页连接探测可选用途；保存后审计只新增改动的那几项
- [ ] 图库批量加收藏生效；导出可选 CSV
- [ ] 仪表盘有「目录占用」；运维页有直读契约区块

**体验**
- [ ] 每个列表页：骨架 → 数据/空态 → 滚动加载更多，操作后不丢位置
- [ ] 所有删除/清空走弹窗，不再有浏览器原生 confirm / prompt
- [ ] `/` 聚焦全局搜索；抽屉内 Esc 关闭、← → 翻图
- [ ] 后端未启动时显示断连横幅而不是白屏

## 8. 遗留项（本次明确未做）

1. **视觉走查**：需要启动服务后人工过一遍（见 §5 末）。
2. **分类合并**：后端 `update_category` 改名已级联，但「两个分类合并为一个」无接口，界面也没有。
3. **幻灯片 / 旋转 / 打开所在位置 / 目录层级树 / 剪贴板轮询 / 上传图找相似 / 纠错计数筛选 / 实时速率仪表**：均需新增后端能力，不在本轮范围（已记在 `docs/第一次/使用指南.md` 第 9 节）。
4. **数据库文件路径**：`/api/stats/system` 不返回路径，运维页直读契约写的是默认值 `data/library.db`；若改了 `PA_DATA_DIR`，页面文案需要同步（改后端加字段才是正解，本轮不动后端）。
