## 一、需求清单（我的原始需求）

### 1.1 一句话定位

**建一个规范化的图片索引数据库，作为本机 Agent 生态（QClaw / openclaw / workbuddy 等）的图片记忆与检索基建。**
**找图是能力，索引是本体。** Web 界面只是管索引、做人工审核的工具，不是主角。

### 1.2 原始需求（11 条，我的原话）

| # | 我说的原话 | 落到哪个功能 |
|---|---|---|
| 1 | 使用 ai 对图片进行分析 | F2 识图管线 |
| 2 | 要能自己配置 ai 模型 | F5 设置（模型自配） |
| 3 | 自己指定分析哪些文件夹以及他的子目录 | F1 入库（目录**手动登记** + 白名单 + 递归开关） |
| 4 | 要有一个对话的地方，但是主要是对外提供数据库索引 | F11 对话 + F12 SQLite 直读（对话是副，索引是主） |
| 5 | 分析图片要有 ocr，单独存放在一个表里，记录图中的文字信息 | F2.OCR（按需触发，独立表） |
| 6 | 要有一个资料库，里面存放标准的人物，即手动识别过的绝对真实信息 | F7 参考资料库 |
| 7 | 图片要有识图模型分析出的内容，也要有标签；也要有记录元素的功能。标签跟元素可以重叠，标签更泛，元素更具体，元素要多，要全，要包含几乎能识别到的所有东西 | F2（ai_tags 与 elements 两套字段） |
| 8 | 要能指定规则，像资料库一样：某个文件夹下的都是什么大类；图片右下角有 uid 判定是原神截图 | F13 分类规则引擎 |
| 9 | 不仅可以自定义的分类，也要能手动分类 | F14 自定义分类 + 手动归类 |
| 10 | 要能隐藏照片，不显示在前端界面，放进一个隐藏的地方 | F15 隐藏区 |
| 11 | 因为识图模型有速率，也设一个限制 | F2 成本记账 + 每日上限（G3） |

### 1.3 重写目标（上一版的教训，这版必须成立）

1. **SQLite 为唯一存储**——元数据、全文索引、向量全部入库；**数据库文件本身即对外接口**，任何 Agent 可只读直连（**不做 MCP Server**）
2. 检索走**关键词 + 语义双路混合**（借鉴小遥搜索的混合架构），"搜黄昏能找到傍晚的图"
3. AI 能力全走 **OpenAI 兼容协议**——云端 API 和本地 Ollama / LM Studio 通吃
4. **配置全部可自配**，但**不许拿裸 JSON 编辑器糊弄我**（见三章 UI 效果）
5. 密钥存 `.env`（已 gitignore），**界面明文可见、可编辑**；日志与数据库不落密钥

### 1.4 明确不做

语音检索、视频检索、文档检索、多用户、云同步、图片编辑、桌面壳（本地 Web 即可）、**MCP Server（对外只走 SQLite 直读）**。

## 二、功能清单

### 2.1 功能域 F1-F15

| # | 功能 | 要点 |
|---|---|---|
| **F1** | 图片入库 | **图片目录必须用户手动登记，不做任何自动发现/默认扫描**（未登记的目录一概不碰）；多根目录登记、递归扫描、扩展名白名单与 glob 排除可配、每目录递归开关；**增量扫描**（新文件入库、消失文件标记不删记录、mtime 变更重提取）；**离线盘**：盘符不可达标 offline，插回一次扫描复活；**目录级策略**：每目录可配识图开关/大模型/小模型/OCR 档/隐私（永不发云端）/冻结；**导入向导**：先预估（张数/耗时/成本）再分阶段执行（先入库后识别）；提取宽高/大小/mtime/EXIF 拍摄时间/主色调；生成统一缩略图；**内容哈希 MD5 默认开**：同内容共存入库、文件移动改名按 hash 认回原身份（标注不丢） |
| **F2** | AI 识图管线 | OpenAI 兼容 VLM 逐张产出：`category` + `description` + `ai_tags`（3~5 个，与人工 tags 分开存、合并搜）+ `elements` 元素清单（要多要全）+ `text_content` 图中文字（**OCR 按需触发**：VLM 识图时判定"图中含文字"才追加 OCR 请求，结果落**独立表**；无文字图零 OCR 开销，判定阈值与目录强制开关可配）；字段可独立开关省 token；后台队列：并发可配、失败重试上限可配、实时进度、可停止、优先级策略（新图优先/目录权重/FIFO）、**全局限速默认 20 次/分钟（≥3 秒一次，可调）**与过夜限速可配；prompt 界面可编辑多模板；**成本记账**：每次请求记 tokens、界面看累计、批量前预估、**每日上限触顶自动停**；**软失败**：识图服务挂了，入库/管理/关键词搜索照常 |
| **F3** | 搜索（核心） | FTS5 全文（文件名/描述/标签/备注，中文分词友好）；语义向量余弦；**混合 RRF 融合、默认模式**；筛选（分类/标签/评分/收藏/目录/时间）可与搜索叠加，分页双模式（跳页 + **cursor 游标，10 万级不卡**）；**LLM 查询增强**可开关；**同义词组与术语加权**（猫=喵星人）、搜索历史可开关可清除 |
| **F4** | 图库管理 | 标签多值、评分 0-5、收藏、备注；缩略图网格 + 大图查看；批量打标/批量评分；**智能相册**（当前筛选+搜索+排序存为命名视图，侧栏一键回放）；**自定义字段**（text/数值/日期/下拉，详情与筛选动态出现，不入 FTS/向量） |
| **F5** | 系统设置 | 模型配置：识图/嵌入/增强/对话四用途各自绑档案+模型（可跟随）；档案 = base_url + 密钥 + 类型（**密钥明文可见、可编辑、可复制**），支持本地端点；连接探测；目录管理、prompt 编辑、并发/重试/限速参数；**配置项全部 schema 驱动，新增配置零 UI 代码可加** |
| **F6** | 人工纠错与打回 | AI 结果可直接手动修正，保存即生效（人说的就是对的，AI 不用再确认）；可填**纠正说明**后**打回重识别**——下次识别 prompt 携带人类反馈重新生成；打过回的图带"已人工纠错"标记与次数、可筛选；**人工修正永远优先于 AI**（展示与搜索都以人工为准） |
| **F7** | 参考资料库 | 实体卡：名称+别名+类别+特征描述+参考图 1~N；**识别时连图带文注入**——待识别图 + 命中实体参考图 + 资料文本，让模型拿标准照对照认人；**三路注入**：手动关联全量 + 名称/别名硬匹配 + 实体向量召回（top-3），每实体参考图最多 2 张；手动关联图片绑定实体；实体可停用；参考图独立目录存储并压缩省 token |
| **F8** | 文件与图库操作 | **删除双模式**：默认仅移除索引（源文件永不动），可选删源文件但必须走**回收站**可找回，绝不物理直删；打开所在位置；重命名库内同步改绑（hash 身份与标注不变）；移动/复制到其他已扫描目录自动改绑 |
| **F9** | 导入与浏览增强 | 拖文件夹进窗口=添加扫描目录（可拒绝），拖文件=直接入库排队；大图 `←→` 连续切换不退回列表、可旋转；幻灯片全屏轮播可调间隔 Esc 退出；侧栏**真实目录层级树**浏览；Ctrl+V 粘贴导入 |
| **F10** | 扩展功能 | **图库仪表盘**（分类分布/月度趋势/存储大头/识别状态）；**重复清理向导**（MD5 精确组 + dHash 相似聚类，每组引导保留一张，只移索引不动源文件）；**截图自动导入**（30 秒轮询监听目录 + 剪贴板，新图入库并排队识别，可开关）；**以图搜图**（库内选图或上传，纯 embedding 相似检索） |
| **F11** | 对话式问答 | 自然语言问图库（"上个月拍的猫在哪"）：LLM 解析成结构化查询（关键词+时间/分类/评分筛选）→ 混合检索 → LLM 生成回答附图片卡；解析失败/服务挂 = 软失败降级，不死不弹错；**提案队列**：对话中 LLM 给出的实体/标签建议只进提案队列，界面**一键批准**才入库，批准前库零变化 |
| **F12** | SQLite 直读规范 | **数据库文件即对外接口**：本机 Agent 只读直连、不装任何东西、不起任何服务；**只读铁律**：直读只查不写，一切写入经人工 UI，扫描/识别等管理操作不通过直读暴露；隐藏区在直读查询中默认过滤且**无绕过参数**；COALESCE 取值人工字段优先；字段语义与文档逐字一致；随库提供表结构与查询示例文档 |
| **F13** | 分类规则引擎 | IF（目录前缀/后缀/文件名/OCR 文本/分类）→ THEN（设分类/追加标签/进智能相册）；可排序、逐条开关、**首条命中即停**；**两阶段求值**（入库即判 + OCR 完成后复算 + 历史图一键补算）；**试跑先行**（只预览命中不落库）；只写 AI 分类位，人工分类绝不覆盖 |
| **F14** | 自定义分类与手动分类 | 内置 6 类之外自建分类（名称/颜色/表情）；重命名/合并/停用同事务级联全部图片；详情与批量手动归类；**人工分类优先于 AI 分类**；分类单选、标签多选，两维都进筛选与搜索 |
| **F15** | 隐藏区 | 单张或批量隐藏：从图库、搜索、智能相册、**Agent 直读检索**全部消失；文件仍在原处、识别备份照常；侧栏隐藏区集中查看与批量恢复，入口有可见性说明条；与隐私模式区分（隐私=临时 UI 遮罩，隐藏=持久数据状态）；**铁律：前端与 SQLite 直读默认过滤且无绕过参数** |

## 三、效果要求（我预期的效果）

> 这章是"做成什么样我才认"。功能做没做是二章的事，**做出来的东西给我的感受**是这章的事。每一条都是验收底线。

### 3.1 界面效果（这条最优先，上一版就死在这上面）

1. **不许丑，不许糊弄**：所有配置项必须是**表单化/卡片化的友好控件**——档案是卡片（增删改+探测按钮+下拉绑定），规则是卡片，分类是表格。**禁止让我在文本框里手写 JSON**；JSON 编辑器只允许作为高级项藏在折叠区里兜底
2. **视觉统一**：一套设计规范（色板/间距/圆角/阴影/字号），全部页面观感一致；不做花哨动效，要干净、紧凑、信息密度合理
3. **schema 驱动**：新增配置项不该需要改 UI 代码——定义了分组/控件/默认值，设置页自动长出来
4. **状态永远可见**：未保存徽章、加载中、空状态引导、失败原因人话提示——不许有"点了没反应"
5. **中文优先**：界面文案中文，错误信息人话（"缺少 API Key"而不是"E4101"）

### 3.2 找图效果

1. 搜"夕阳下的海滩"，描述里写"傍晚海岸"的图**也要出来**（语义兜底）；搜报错码能命中对应截图（OCR）
2. 默认混合模式：关键词和语义**各取所长自动融合**，不需要我手动切模式
3. 口语化问题（"我上个月拍的猫"）解析成结构化条件，回答里**给结论 + 图片卡**，不是甩一堆链接
4. 10 万张的库，首屏和深翻页**不卡**；关键词搜索 <100ms、向量搜索 <300ms

### 3.3 可靠性效果（软失败）

1. **任何 AI 服务挂掉都不许把系统搞死**：不弹全页错误、不死循环重试——识图挂了入库和搜索照常，嵌入挂了语义自动降级关键词，对话挂了给引导语
2. 断网重试自动续跑、恢复不重复计费；进程重启队列状态接得上
3. 每日上限触顶自动暂停并明说原因，次日恢复

### 3.4 人工优先效果

1. 我改过的分类/描述/标签，**AI 永远不能覆盖**，规则也不能
2. 纠正说明打回后，下一次识别的 prompt 里**必须带着我的话**重新认，不是盲目重抽
3. 资料库里"绝对真实"的人物信息，识别时**连参考图带文本注入**——拿标准照对照认，别凭通用知识硬猜

### 3.5 隐私与安全效果

1. 密钥在设置页**明文可见、可复制**（存 `.env`），但**不进日志、不进数据库、不进导出物**
2. 隐藏区的图，在**前端、搜索、智能相册、SQLite 直读**所有面都搜不到，**没有任何参数能绕过**
3. 删除默认只动索引，删源文件必须走回收站；危险操作要打确认词
4. 隐私模式/敏感守门开着时，一张图都不许发出去（可验证：零外发请求）
5. 服务只监听 127.0.0.1，外部不可达

### 3.6 SQLite 直读效果

1. Agent 打开数据库文件只读直连即可查询——**不需要装任何东西、不需要起任何服务**
2. Agent 查到的永远是"干净"结果：隐藏区排除、COALESCE 取值（人工字段优先）、字段语义与文档一致
3. 对话中给出的实体/标签建议只进提案队列，界面上**一键批准**才真正入库，批准前库零变化

### 3.7 成本效果

1. 每次 AI 花了多少 token、累计花了多少，**界面上一眼可见**
2. 批量识别前先告诉我"这批大概要花多少"；超上限自动停并通知
3. 目录能区别对待：重要目录用大模型、随手截图用小模型、隐私目录永不外发
4. 识图**默认限速 20 次/分钟（3 秒一次）**，当前速率、限速与暂停原因界面一眼可见

### 3.8 一致性效果

1. 同一个数字，仪表盘、统计接口、我手动 SQL 查出来的**必须一致**
2. 文档说有的功能，界面就有；界面有的行为，文档就写——不许对不上
3. 配置改了**立即或保存后生效**（各自标注清楚），不许要重启才生效却不告诉我

## 四、验收标准（逐功能 AC 摘要）

> 全量 AC 见详细 SRS（另册）；此处为每个功能的"必须通过"底线，重写后逐条复测。

| 功能 | 关键 AC |
|---|---|
| F1 入库 | 加目录→增量扫描入库；**未登记目录零扫描**；拔盘标 offline 插回复活；MD5 同内容共存、移动改名认回身份；递归开关生效、父子目录不可同登记；导入向导先预估后分阶段 |
| F2 识图 | 无 Key 启动零外发且队列暂停有提示；并发/重试/优先级生效；**限速默认 20 次/分钟（实测请求间隔 ≥3 秒）**；**OCR 仅对识图判定含文字的图触发并落独立表，无文字图零 OCR 请求**；tokens 记账与预估、每日上限触顶暂停；软失败全链成立 |
| F3 搜索 | 中文关键词命中；语义"搜黄昏找到傍晚"；混合 RRF 默认；cursor 深分页无重复遗漏；同义词展开、历史开关；增强失败回退原词 |
| F4 管理 | 批量打标/评分；智能相册回放=原查询；自定义字段定义即出现、不入 FTS/向量 |
| F5 设置 | 四用途独立绑定（含跟随）；探测出延迟与能力；schema 驱动渲染、脏键保存、恢复默认、审计回滚；密钥明文可见可复制 |
| F6 纠错 | 人工修正即生效且不被覆盖；打回携带纠正说明重识别；打回计数与筛选；FTS 即时更新 |
| F7 资料库 | 实体卡+参考图；三路注入命中；注入上限生效；停用实体不注入 |
| F8 文件操作 | 默认只删索引；删源文件走回收站可找回；重命名/移动后 hash 身份与标注不变 |
| F9 浏览 | 拖拽两选导入；大图连续翻页旋转；幻灯片 Esc 退出；目录树前缀筛选；粘贴导入 |
| F10 扩展 | 仪表盘数字与手算一致；清理向导执行后组内仅剩保留项且源文件在；**监听目录新图 ≤35 秒入库并按开关排队**；以图搜图相似命中 |
| F11 对话 | 结构化解析出关键词+筛选并回显；回答+图片卡；空解析给引导语；服务挂（模拟开关）全链降级零调用；超字数 400；**提案批准前库零变化、批准后生效** |
| F12 直读 | SQLite 只读直连可查；只读铁律（一切写入经人工 UI）；隐藏区默认过滤且无绕过；COALESCE 人工字段优先；字段语义与文档一致 |
| F13 规则 | 优先级首命中即停；试跑不落库；OCR 规则延迟复算；人工分类不被覆盖；补算幂等 |
| F14 分类 | 内置 6 类不可删改；重命名/合并级联全部图片且智能相册跟随；人工 COALESCE 优先 |
| F15 隐藏区 | 隐藏后前端/搜索/相册/直读全部不可见；恢复即回来；识别备份照常 |

**横切验收（非功能）**

- 性能：10 万张种库，首屏流畅、关键词 <100ms、向量 <300ms、扫描 ≥300 文件/秒、仪表盘 P95 <500ms
- 安全：只监听 127.0.0.1；日志、数据库与导出物无密钥（设置页明文可见除外）；路径穿越全拒；隐私模式零外发；危险操作确认词
- 文档一致性：文档/界面/实现三方对得上（配置键、端点、字段、错误码逐字一致）

## 五、非功能需求

| 项 | 要求 |
|---|---|
| 隐私 | 图片文件不出本机；仅识图/嵌入时发往**用户自选**服务（选本地模型可全离线） |
| 密钥 | 存 `.env`，已 gitignore；设置页明文可见、可编辑；不进日志/数据库/导出物 |
| 性能 | 万级流畅、10 万级不卡（见四章横切验收） |
| 健壮 | 失败不阻塞主流程、断点续跑、关键操作有日志 |
| 环境 | Windows 10/11 + Python 3.12 + Chrome/Edge；后端轻依赖（FastAPI/uvicorn/Pillow/httpx/jieba/numpy），前端 Vue3 + Vite |
| 交付 | 本地 Web 形态（`python server.py` → 浏览器打开），打包 Release zip 即可，不做桌面壳 |
